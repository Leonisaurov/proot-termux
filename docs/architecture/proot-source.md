proot
=====
[![Travis build status](https://travis-ci.org/termux/proot.svg?branch=master)](https://travis-ci.org/termux/proot)

This is a fork of [the PRoot project](https://github.com/proot-me/PRoot/)
packaged for Android/Termux. The executable remains standalone: rootfs,
bindings, environment, and policy are supplied by the caller. No Termux
directory or consumer-specific preset is implicit in the executable.
